# Aiden Azarnoush — Engineering Portfolio

Personal portfolio of **Aiden Azarnoush**, a Structures, Thermal & Fluids Analysis Engineer.

**[Visit the portfolio →](https://aiden-azarnoush.github.io/)**

## About the website

A continuous, scrolling portfolio presenting professional experience, education, publications, and interactive engineering projects. Subtle engineering animations accompany the content: airflow, a turbine, a shuttle ascent, airfoil streamlines and wake, and heat-transfer lines.

The animations are illustrative design elements, not simulation results.

## Portfolio sections

- **About Me** — professional introduction, core competencies, software, programming languages, and profile links.
- **Professional Experience** — expandable employer and project details.
- **Education** — degrees, universities, and academic focus areas.
- **Publications** — publication details and a link to Google Scholar.
- **Projects** — links to interactive engineering tools and their source repositories.
- **Contact Me** — email and research profile links.

## Features

- Responsive layout for desktop and mobile screens.
- Light and dark themes with a sun/moon toggle and a locally saved preference where browser storage is available.
- Floating section dots that track scrolling and link to each section.
- A floating back-to-top arrow that appears after scrolling down.
- Expandable work and publication details.
- Blue-to-red thermal gradient accents.
- Reduced-motion support for visitors who prefer less animation.

The portfolio is built with HTML, CSS, and JavaScript. Its background visuals use the Canvas API. No build step, package installation, or backend is required.

## Preview locally

Download `index.html` and open it in a modern web browser. The portfolio and its animations are self-contained; external project and profile links require an internet connection.

## Update the portfolio

1. Keep a copy of the current `index.html` before replacing it.
2. Open the replacement locally and review its content and navigation.
3. Upload the replacement `index.html` to the root of this repository, preserving the filename.
4. Upload this `README.md` alongside it and commit the changes.
5. Once the existing GitHub Pages deployment completes, review the live portfolio.

The README documents the project on GitHub; it does not replace the website's homepage.

### Editing content

In `index.html`, structured portfolio data is stored in the JSON block with `id="as-data"`. It includes employers and work projects, education, publications, engineering tools, repository links, and skills. The introduction and contact details appear in the surrounding HTML.

After editing, check both themes, section navigation, expandable details, and the mobile layout.
